# Screenshot Guide

Capture these from your own completed lab, and save using the exact filenames:

1. `01-gpo-overview.png` — GPMC with the GPO selected and its link/scope visible.
2. `02-password-policy.png` — Password Policy folder showing the settings list.
3. `03-minimum-length.png` — Minimum password length = 12.
4. `04-complexity-history.png` — Complexity = Enabled and history = 5 (two captures may be combined into one figure).
5. `05-maximum-age.png` — Maximum password age = 90 days.
6. `06-gpupdate.png` — Successful `gpupdate /force` and, ideally, verification of effective domain password settings.
7. `07-password-rejection.png` — Test password rejected for policy violation; do not expose the actual password.

Use real screenshots; redact sensitive details. Do not fabricate validation evidence.
